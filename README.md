# cimw100b-miles-website

An old website I made in 2022 for a community college web development class. It's not much, but it was my first real foray into programming stuff and so it has a special place in my heart (although it is quite ugly).

It's primarily just static pages consisting of HTML/CSS with a few animations and a couple of JavaScript additions here and there. Not too bad for a first website, actually, and I'm a big fan of static page websites for small projects like this that don't really have a tech stack or need anything loaded dynamically; it's simple, fast, and uncomplicated.

You can download the repository and open the webpages and navigate the website that way, although since all the image files I found/made for this project were on a different computer, I don't currently have them here, which causes the website to look a bit off. I actually found out recently that this website is actually still being hosted on my CC's web server, so if you would like to experience the site in its full static glory, you can visit it here: http://net.saddleback.edu/mdavis114/cimw100b/final/index.html
